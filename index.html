What is this project?

This project is a simple dashboard that connects to GitLab and shows useful project information in one place. Instead of clicking through multiple GitLab pages, a team could quickly see what work is open, what work is finished, how much progress has been made, and how the team is doing overall.

The goal is to learn GitLab and APIs while building a tool that that tracks the very project being used to create it.

What is the GitLab API?

An API is a way for one program to ask another program for information. In this project, our app would ask GitLab for data such as issues, milestones, labels, users, and completed work.

For example, instead of a person manually counting closed issues, the app could ask GitLab: “Which issues are closed for this milestone?” Then the app could calculate and display the answer.

Semester Scope

  1. Connect to GitLab and retrieve project issue data
  2. Display open, closed, and upcoming issues
  3. Calculate team velocity from completed issue weights
  4. Show milestone progress in a clean dashboard
  5. Add stretch features if the core version is finished early
